# Малювання

Yu вміє малювати, і для цього не треба нічого доставляти. Малюнок з'являється у вкладці
«Малюнок» одразу після запуску.

Полотно — це аркуш 600 на 400 точок. Точка `0, 0` — лівий верхній кут: `x` росте праворуч, `y` —
вниз. Тому `коло(300, 200, 50)` малює коло посередині.

## Фон і коло

`фон` зафарбовує все полотно, `колір` задає колір для наступних фігур, а `коло` малює коло за
центром і радіусом.

```yu
фон("блакитний")
колір("жовтий")
коло(300, 120, 60)
```

Назви кольорів пиши в лапках: `"червоний"`, `"жовта"`, `"синє"` — рід не важливий. Працюють і
англійські назви, і код виду `"#ff8800"`, і `"випадковий"`.

## Прямокутники

`прямокутник` бере лівий верхній кут, ширину й висоту.

```yu
фон("блакитний")
колір("зелений")
прямокутник(0, 300, 600, 100)
колір("білий")
прямокутник(220, 180, 160, 120)
колір("коричневий")
прямокутник(280, 250, 40, 50)
```

Це вже будинок: трава, стіна й двері.

## Лінії й товщина

`лінія` малює пряму від однієї точки до іншої, а `товщина` каже, якою грубою буде лінія.

```yu
колір("червоний")
товщина(8)
лінія(100, 300, 300, 150)
лінія(300, 150, 500, 300)
```

## Напис і своє полотно

`напис` пише текст просто на малюнку, а `полотно` змінює розмір аркуша. Викликай `полотно` на
самому початку програми.

```yu
полотно(400, 200)
фон("білий")
колір("синій")
напис("Привіт від Yu", 90, 90)
```

Готовий малюнок можна зберегти: над малюнком є кнопки SVG і PNG. У терміналі те саме робить
`yu будинок.yu --svg будинок.svg`.
