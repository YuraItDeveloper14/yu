# Перша програма

Yu працює просто в браузері: відкрий [yu-lang.vercel.app](https://yu-lang.vercel.app) — і можна
писати. Встановлювати нічого не треба.

Зліва в Студії редактор: туди ти пишеш програму. Справа дві вкладки: «Малюнок» показує те, що
програма намалювала, а «Термінал» — те, що вона написала словами. Кнопка «Запустити» вгорі
справа запускає програму, і те саме робить Ctrl+Enter.

## Скажи щось

Найкоротша програма мовою Yu — це одне слово `скажи` і текст у дужках:

```yu
скажи("Привіт, світе!")
```

```text
Привіт, світе!
```

Розберемо по частинах. `скажи` — команда: «напиши це в терміналі». Круглі дужки показують, що
саме сказати. Лапки означають, що всередині текст, а не назва чогось. Натисни «Запустити» — і
Студія відкриє «Термінал» із твоїм рядком.

## Кілька рядків

Програма виконується згори вниз, рядок за рядком. Рядок, який починається з `#`, Yu не виконує:
це коментар, записка для людини.

```yu
# Цей рядок Yu не виконує
скажи("Мене звати Юрій")
скажи("Мені 15 років")
```

```text
Мене звати Юрій
Мені 15 років
```

## Yu вміє рахувати

У дужках може бути не лише текст, а й приклад. Кілька значень пиши через кому: Yu надрукує їх в
одному рядку через пробіл.

```yu
скажи("2 + 2 =", 2 + 2)
```

```text
2 + 2 = 4
```

Текст у лапках Yu друкує як є, а приклад без лапок рахує. Тому `"2 + 2 ="` лишилося написом, а
`2 + 2` перетворилося на `4`.

## Спробуй сам

1. Напиши програму, яка друкує два рядки про тебе: як тебе звати і звідки ти.

```

2. Нехай Yu порахує 7 × 8 і напише результат із підписом.

<details>
<summary>Показати відповідь</summary>

```

```text
7 × 8 = 56
```
