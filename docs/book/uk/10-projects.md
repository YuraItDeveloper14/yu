# Три проєкти

Далі три готові програми. Кожна складена з того, що вже було в книзі: умови, цикли, списки,
функції й малювання. Запусти, а потім зміни під себе — так найкраще запам'ятовується.

## Вгадай число

Програма задумала число, а ти вгадуєш. `поки` повторює питання, доки відповідь не збіглася.

```input
5
7
```

```yu
секрет = 7
спроба = число(запитай("Вгадай число від 1 до 10:"))
поки спроба != секрет:
    скажи("Не те. Спробуй ще")
    спроба = число(запитай("Ще раз:"))
скажи("Вгадав!")
```

```text
Не те. Спробуй ще
Вгадав!
```

Заміни `7` на `випадкове(1, 10)` — і програма щоразу загадуватиме нове число.

## Будинок

Стіни — прямокутники, а дах малює черепашка із заливкою. Спершу вона мовчки переходить у лівий
верхній кут стіни, і вже звідти обходить трикутник.

```yu
фон("блакитний")
колір("зелений")
прямокутник(0, 300, 600, 100)
колір("білий")
прямокутник(220, 180, 160, 120)
колір("червоний")
підніми_перо()
назад(80)
ліворуч(90)
вперед(20)
праворуч(90)
опусти_перо()
почни_заливку()
повтори 3 рази:
    вперед(160)
    ліворуч(120)
заверши_заливку()
```

Додай сонце колом, двері прямокутником, напис із назвою вулиці — полотно твоє.

## Вікторина

Кожне правильне питання додає бал. Порівнювати текст можна так само, як числа: `==`.

```input
Київ
4
```

```yu
бал = 0
якщо запитай("Столиця України?") == "Київ":
    бал = бал + 1
якщо число(запитай("2 + 2 = ?")) == 4:
    бал = бал + 1
скажи("Твій бал:", бал, "з 2")
```

```text
Твій бал: 2 з 2
```
