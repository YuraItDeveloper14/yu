# Числа й текст

У першому розділі Yu друкував те, що ми написали в лапках. Тепер навчимося зберігати значення,
рахувати й питати щось у людини.

## Значення мають імена

Ім'я запам'ятовує значення. Знак `=` кладе значення в ім'я:

```yu
вік = 15
скажи("Мені", вік, "років")
```

```text
Мені 15 років
```

Ліворуч від `=` завжди ім'я, праворуч — значення. Імена можна писати українською, і в них
дозволений апостроф: `ім'я`.

## Рахунок

Yu рахує `+`, `-`, `*` (множення), `/` (ділення) і `%` — остачу від ділення.

```yu
сума = 7 + 8
скажи("Сума:", сума)
скажи("Половина:", сума / 2)
скажи("Остача від ділення на 4:", сума % 4)
```

```text
Сума: 15
Половина: 7.5
Остача від ділення на 4: 3
```

## Текст склеюється

Той самий `+` для тексту означає «склей». Число теж можна приклеїти до тексту.

```yu
ім'я = "Оля"
скажи("Привіт, " + ім'я + "!")
```

```text
Привіт, Оля!
```

Зверни увагу на пробіл у `"Привіт, "`: без нього слова злиплися б.

## Запитай у людини

`запитай` показує питання і чекає, поки людина введе відповідь. У Студії питання з'являється в
терміналі, і відповідь ти пишеш просто там.

```input
Оля
```

```yu
ім'я = запитай("Як тебе звати?")
скажи("Привіт, " + ім'я + "!")
```

```text
Привіт, Оля!
```

## Текст і число — різні речі

`запитай` завжди повертає текст, навіть якщо людина ввела цифри. Щоб рахувати, перетвори його на
число командою `число`. Назад у текст перетворює `текст`.

```input
12
```

```yu
роки = число(запитай("Скільки тобі років?"))
скажи("Через рік буде", роки + 1)
```

```text
Через рік буде 13
```

## Округли й випадкове

`округли` дає найближче ціле число.

```yu
скажи("2.5 округлюється до", округли(2.5))
```

```text
2.5 округлюється до 3
```

`випадкове` щоразу дає інше число, тому результату тут немає: запусти й побачиш свій.

```yu
скажи("Кубик:", випадкове(1, 6))
```
