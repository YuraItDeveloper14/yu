# Цикли

Комп'ютер не втомлюється робити те саме. Цикл — це спосіб сказати «повтори оце» й не писати
однакові рядки руками.

## Повтори

`повтори` робить блок задану кількість разів. Після числа пиши `раз`, `рази` чи `разів` — як
звучить природно.

```yu
зірочки = ""
повтори 5 разів:
    зірочки = зірочки + "*"
скажи(зірочки)
```

```text
*****
```

## Для … від … до

Часто потрібне саме число кроку. `для` рахує від першого числа до другого, обидва кінці включно, і
щоразу кладе поточне число в ім'я.

```yu
для i від 1 до 5:
    скажи(i, "× 7 =", i * 7)
```

```text
1 × 7 = 7
2 × 7 = 14
3 × 7 = 21
4 × 7 = 28
5 × 7 = 35
```

## Крок

Якщо рахувати треба не по одному, додай `крок`.

```yu
для i від 0 до 20 крок 5:
    скажи(i)
```

```text
0
5
10
15
20
```

## Поки

`поки` повторює блок, доки умова правдива. Стеж, щоб умова колись стала неправдивою, бо інакше
програма не закінчиться. У Студії такий цикл можна зупинити кнопкою «Стоп».

```yu
гроші = 10
поки гроші >= 3:
    гроші = гроші - 3
скажи("Лишилось", гроші)
```

```text
Лишилось 1
```

## Стоп і далі

`стоп` виходить із циклу зовсім, а `далі` пропускає решту блоку й переходить до наступного
повтору.

```yu
для i від 1 до 10:
    якщо i == 5:
        стоп
    якщо i % 2 == 0:
        далі
    скажи(i)
```

```text
1
3
```
