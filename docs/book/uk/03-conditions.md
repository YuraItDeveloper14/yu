# Умови

Поки що програма виконувала всі рядки підряд. Умова дозволяє їй вибирати: зробити щось або
пропустити.

## Якщо

`якщо` перевіряє умову. Рядки під ним із відступом у чотири пробіли виконаються, лише коли умова
правдива.

```yu
температура = 25
якщо температура > 20:
    скажи("Сьогодні тепло")
```

```text
Сьогодні тепло
```

Двокрапка в кінці рядка відкриває блок, а відступ показує, що саме до нього належить. Порівнювати
можна так: `>` більше, `<` менше, `>=` більше або дорівнює, `<=` менше або дорівнює, `==` дорівнює,
`!=` не дорівнює.

Одне дорівнює `=` кладе значення в ім'я, а подвійне `==` порівнює. Це різні речі.

## Інакше, інакше якщо

Якщо умова неправдива, виконається блок під `інакше`. Між ними можна поставити скільки завгодно
`інакше якщо`: Yu візьме перший блок, умова якого правдива.

```yu
бал = 7
якщо бал >= 10:
    скажи("Відмінно")
інакше якщо бал >= 6:
    скажи("Добре")
інакше:
    скажи("Ще трохи")
```

```text
Добре
```

## І, або, не

Умови можна поєднувати. `і` правдиве, коли правдиві обидві частини, `або` — коли хоч одна, а `не`
перевертає відповідь.

```yu
вік = 12
якщо вік > 6 і вік < 18:
    скажи("Ходить до школи")
скажи("Ще не дорослий:", не (вік >= 18))
```

```text
Ходить до школи
Ще не дорослий: так
```

## Так, ні, нічого

Порівняння дає одне з двох значень: `так` або `ні`. Є ще `нічого` — так Yu каже, що значення
немає.

```yu
дощ = ні
скажи("Дощ:", дощ)
знахідка = нічого
скажи("Знайшли:", знахідка)
```

```text
Дощ: ні
Знайшли: нічого
```

## Спробуй сам

1. Перевір, чи число парне. Підказка: парне число ділиться на 2 без остачі.

<details>
<summary>Показати відповідь</summary>

```yu
перевірка = 10
якщо перевірка % 2 == 0:
    скажи("Парне")
інакше:
    скажи("Непарне")
```

```text
Парне
```

</details>

2. Квиток коштує 50, а дітям до 12 років безкоштовно. Надрукуй ціну для віку 10.

<details>
<summary>Показати відповідь</summary>

```yu
вік = 10
якщо вік < 12:
    скажи("Ціна: 0")
інакше:
    скажи("Ціна: 50")
```

```text
Ціна: 0
```

</details>
