# Функції

Коли той самий шматок програми потрібен у кількох місцях, йому дають ім'я. Такий названий шматок
називається функцією.

## Дай блокові ім'я

`функція` починає опис: ім'я, а в дужках — параметри, тобто значення, які функція отримає під час
виклику. Рядки з відступом — тіло функції. Саме по собі воно не виконується: воно чекає на виклик.

```yu
функція привітай(ім'я):
    скажи("Привіт, " + ім'я + "!")

привітай("Оля")
привітай("Тарас")
```

```text
Привіт, Оля!
Привіт, Тарас!
```

## Поверни відповідь

Функція може не лише друкувати, а й віддавати значення назад. Це робить `поверни`.

```yu
функція площа(ширина, висота):
    поверни ширина * висота

скажи("Площа кімнати:", площа(4, 3))
```

```text
Площа кімнати: 12
```

Після `поверни` функція одразу закінчується, навіть якщо нижче є ще рядки.

## Функція може кликати себе

Усередині функції можна викликати її ж. Головне — щоб був випадок, коли вона вже не кличе себе, а
просто повертає відповідь.

```yu
функція факторіал(n):
    якщо n <= 1:
        поверни 1
    поверни n * факторіал(n - 1)

скажи("5! =", факторіал(5))
```

```text
5! = 120
```

## Спробуй сам

1. Напиши функцію, яка повертає менше з двох чисел.

<details>
<summary>Показати відповідь</summary>

```yu
функція менше(a, b):
    якщо a < b:
        поверни a
    поверни b

скажи(менше(9, 4))
```

```text
4
```

</details>

2. Напиши функцію, яка друкує слово задану кількість разів.

<details>
<summary>Показати відповідь</summary>

```yu
функція повтори_слово(слово, скільки):
    повтори скільки разів:
        скажи(слово)

повтори_слово("Yu", 3)
```

```text
Yu
Yu
Yu
```

</details>
