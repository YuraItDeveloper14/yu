# Списки

Одне ім'я зберігає одне значення. А якщо їх багато: список друзів, покупок, оцінок? Для цього в Yu
є список.

## Список значень

Список пишеться у квадратних дужках, значення розділяються комами. Елементи нумеруються з 1, тож
`друзі[1]` — перший.

```yu
друзі = ["Оля", "Тарас", "Марко"]
скажи("Перший:", друзі[1])
скажи("Скільки:", довжина(друзі))
```

```text
Перший: Оля
Скільки: 3
```

`довжина` каже, скільки в списку елементів. Для тексту вона каже, скільки в ньому букв.

## Додай у кінець

Список можна доповнювати під час роботи програми: `додай` кладе значення в кінець.

```yu
покупки = ["хліб"]
додай(покупки, "молоко")
скажи(покупки)
```

```text
["хліб", "молоко"]
```

## Пройди список

`для … у` бере елементи один за одним і кладе кожен у ім'я.

```yu
покупки = ["хліб", "молоко", "яблука"]
для що у покупки:
    скажи("Купити:", що)
```

```text
Купити: хліб
Купити: молоко
Купити: яблука
```

Замість `у` можна написати `в` — як зручніше читати.

## Порахуй усе разом

Список і цикл разом дають майже будь-який підрахунок.

```yu
оцінки = [7, 9, 10, 8]
сума = 0
для оцінка у оцінки:
    сума = сума + оцінка
скажи("Середня:", сума / довжина(оцінки))
```

```text
Середня: 8.5
```

2. Знайди найбільше число у списку.

<details>
<summary>Показати відповідь</summary>

```yu
числа = [3, 17, 8]
найбільше = числа[1]
для n у числа:
    якщо n > найбільше:
        найбільше = n
скажи("Найбільше:", найбільше)
```

```text
Найбільше: 17
```
